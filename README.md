# Design of a Dynamic Process Simulation for Modeling and Control of an Interacting Two-Tank System
This repository contains a standalone dynamic process simulation of an interacting two-tank system developed using MATLAB App Designer and Simulink.

Features:
- Two interacting tanks: V-1 and V-1X
- FIC2003X and FIC2004X flow control loops
- LIC2003A level control loop
- Manual and automatic controller modes
- Valve hysteresis effects
- Gravity-driven level equilibration
- Pump controls, alarms, and real-time trends

Files:
- 'DPS_HMI.mlapp' - MATLAB App Designer HMI
- 'DPS_model.slx' - Simulink process model
